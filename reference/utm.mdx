The `utm` prop passes UTM tracking parameters to the Calendly scheduling page. This lets you attribute bookings to specific marketing campaigns, traffic sources, and ad creatives directly within your analytics tools and the Calendly analytics dashboard.

## TypeScript Type

```ts
type Utm = Optional<{
  utmCampaign: string
  utmSource: string
  utmMedium: string
  utmContent: string
  utmTerm: string
  salesforce_uuid: string
}>
```

All fields are optional. Only the fields you provide are appended to the Calendly URL as query parameters. Omitting the `utm` prop entirely leaves the URL unchanged.

---

## Fields

<ParamField body="utmCampaign" type="string">
  The name of the marketing campaign driving traffic to this scheduling page. Appended to the Calendly URL as the `utm_campaign` query parameter (e.g. `"q4-2024-product-launch"` → `utm_campaign=q4-2024-product-launch`).
</ParamField>

<ParamField body="utmSource" type="string">
  The traffic source — identifies which site, platform, or channel sent the visitor. Appended as the `utm_source` query parameter (e.g. `"homepage"`, `"newsletter"`, `"google"`).
</ParamField>

<ParamField body="utmMedium" type="string">
  The marketing medium — describes the type of channel used. Appended as the `utm_medium` query parameter (e.g. `"cta-button"`, `"email"`, `"cpc"`).
</ParamField>

<ParamField body="utmContent" type="string">
  An identifier for the specific ad or content variant that was clicked. Useful for A/B testing. Appended as the `utm_content` query parameter (e.g. `"hero-banner"`, `"sidebar-link"`).
</ParamField>

<ParamField body="utmTerm" type="string">
  The paid search keyword that triggered the ad. Appended as the `utm_term` query parameter (e.g. `"scheduling software"`).
</ParamField>

<ParamField body="salesforce_uuid" type="string">
  A Salesforce UUID used to associate the booking with a specific lead or contact in your Salesforce CRM. Passed directly as the `salesforce_uuid` query parameter (key name is unchanged — no camelCase conversion).
</ParamField>

---

## Usage Example

```vue
<template>
  <CalendlyInlineWidget
    url="https://calendly.com/your-link/30min"
    :utm="{
      utmSource: 'homepage',
      utmMedium: 'cta-button',
      utmCampaign: 'q4-2024-launch',
    }"
  />
</template>
```

<Note>
  UTM parameters are URL-encoded and appended to the Calendly scheduling page URL as query string parameters. They will appear in your **Calendly analytics dashboard** under the reporting section, allowing you to compare booking rates across campaigns and traffic sources.
</Note>
