Nuxt Calendly is a Nuxt 3 module that brings the full power of Calendly's embed widgets into your application. Drop in an inline scheduling widget, launch a popup on button click, or use the composables to programmatically control every aspect of Calendly — all fully typed with TypeScript.

## Quick install

<Steps>
  <Step title="Add the module">
    ```bash
    npx nuxi@latest module add calendly
    ```
  </Step>
  <Step title="Register in nuxt.config.ts">
    ```ts nuxt.config.ts
    export default defineNuxtConfig({
      modules: ['nuxt-calendly'],
    })
    ```
  </Step>
  <Step title="Use a component">
    ```vue
    <template>
      <CalendlyInlineWidget url="https://calendly.com/your-link/30min" />
    </template>
    ```
  </Step>
</Steps>

<Note>
  Components are auto-imported — no manual `import` statements needed in your Vue files.
</Note>
