This guide walks you through installing `nuxt-calendly`, registering it in your Nuxt config, and rendering your first Calendly scheduling widget. By the end you will have an inline embed, a popup button, and an example of the `useCalendly()` composable all working in your Nuxt 3 project.

<Steps>
  <Step title="Install the package">
    The fastest way to add the module is with the Nuxt CLI:

    ```bash
    npx nuxi@latest module add calendly
    ```

    Prefer a manual install? Use your package manager of choice:

    <CodeGroup>
      ```bash npm
      npm install nuxt-calendly
      ```

      ```bash yarn
      yarn add nuxt-calendly
      ```

      ```bash pnpm
      pnpm add nuxt-calendly
      ```
    </CodeGroup>
  </Step>

  <Step title="Register the module in nuxt.config.ts">
    Add `nuxt-calendly` to the `modules` array. The `calendly` key is optional — omitting it uses all defaults.

    ```ts nuxt.config.ts
    export default defineNuxtConfig({
      modules: ['nuxt-calendly'],

      // optional — all values shown are the defaults
      calendly: {},
    })
    ```
  </Step>

  <Step title="Embed the inline widget">
    Drop `<CalendlyInlineWidget>` into any page or component. The `url` prop is the only required field — point it at your Calendly scheduling link.

    ```vue pages/book.vue
    <template>
      <div>
        <h1>Book a meeting</h1>

        <CalendlyInlineWidget
          url="https://calendly.com/your-link/30min"
        />
      </div>
    </template>
    ```

    <Note>
      Replace `https://calendly.com/your-link/30min` with your real Calendly scheduling link.
    </Note>
  </Step>

  <Step title="Prefill user data (optional)">
    Pass the `prefill` prop to pre-populate the visitor's name, email, and other fields. All `prefill` properties are optional.

    ```vue pages/book.vue
    <template>
      <div>
        <h1>Book a meeting</h1>

        <CalendlyInlineWidget
          url="https://calendly.com/your-link/30min"
          :prefill="{
            name: 'Jane Doe',
            email: 'jane@example.com',
            firstName: 'Jane',
            lastName: 'Doe',
          }"
        />
      </div>
    </template>
    ```
  </Step>
</Steps>

## Popup Button Example

Use `<CalendlyPopupButton>` to open the Calendly scheduler inside a modal overlay when the visitor clicks a button. Pass the `rootElement` prop as a reference to the DOM node the modal should be appended to — typically `document.body`.

```vue pages/contact.vue
<template>
  <div ref="root">
    <h1>Contact us</h1>

    <CalendlyPopupButton
      url="https://calendly.com/your-link/30min"
      :root-element="root"
      text="Schedule a call"
    />
  </div>
</template>

<script lang="ts" setup>
  import { ref } from 'vue'

  const root = ref<HTMLElement>()
</script>
```

## Composable-Based Example

Use `useCalendly()` when you need full programmatic control — for example, opening the popup from a custom UI element:

```vue pages/demo.vue
<template>
  <div>
    <button @click="openPopup">Open Calendly</button>
  </div>
</template>

<script lang="ts" setup>
  const calendly = useCalendly()

  const openPopup = () => {
    calendly.showPopupWidget('https://calendly.com/your-link/30min')
  }
</script>
```

Use `useCalendlyEventListener()` to react to scheduling events — for example, firing analytics when a meeting is booked:

```vue pages/demo.vue
<script lang="ts" setup>
  useCalendlyEventListener({
    onEventScheduled: (e) => {
      console.log('Meeting booked!', e.data.payload.event.uri)
    },
    onDateAndTimeSelected: () => {
      console.log('Date and time selected')
    },
  })
</script>
```

<Tip>
  All components (`CalendlyInlineWidget`, `CalendlyPopupButton`, `CalendlyPopupWidget`) and composables (`useCalendly`, `useCalendlyEventListener`) are auto-imported by Nuxt — you never need to write a manual `import` statement.
</Tip>
